# MyCompany - Адаптивный корпоративный сайт

Этот проект представляет собой современный адаптивный корпоративный сайт для компании "MyCompany". Сайт полностью адаптирован для всех устройств и включает все необходимые разделы для представления компании в интернете.

## 🚀 Особенности

- **Полностью адаптивный дизайн** - оптимизирован для мобильных устройств, планшетов и десктопов (брейкпоинт 1050px)
- **Современная CSS-архитектура** - модульная структура стилей
- **Интерактивная навигация** - бургер-меню для мобильных устройств
- **Чистый семантический HTML5**
- **Кроссбраузерная совместимость**

## 🎨 Секции сайта

1. **Home** - Приветственная секция с основным заголовком
2. **About** - Информация о компании с описанием миссии
3. **Team** - Карточки членов команды
4. **Services** - Услуги компании
5. **Clients** - Логотипы клиентов
6. **Portfolio** - Галерея работ
7. **Testimonials** - Отзывы клиентов
8. **Contact** - Контактная форма

## 💡 Технические особенности

### Адаптивность

- Flexbox и Grid Layout для современных макетов
- Медиа-запросы для адаптации под разные экраны
- Мобильное меню с бургер-иконкой

### Стилизация

- Использование CSS-переменных (где уместно)
- Псевдоэлементы для декоративных элементов
- Плавные переходы и hover-эффекты
- Современные CSS-свойства

### JavaScript

- Простой скрипт для переключения мобильного меню
- Неинтрузивный подход
- Совместимость со старыми браузерами

## 🛠 Используемые технологии

- **HTML5** - Семантическая разметка
- **CSS3** - Flexbox, Grid, медиа-запросы
- **JavaScript (ES6)** - Базовая интерактивность
- **Google Fonts** - Шрифт Open Sans
- **CSS Reset** - Единообразное отображение во всех браузерах

## 📱 Поддержка браузеров

- Firefox (последние версии)
